Gen402 — x402 Data Marketplace

Paid data on GenLayer (studionet, chain 61999). No facilitator, no API keys: you pay the Intelligent Contract, the gateway checks your access on-chain, then serves the data. The contract itself fetches each listing's source and its validators' LLMs judge whether the data matches the listing.

Try the 402 flow

  1. Pick a listing below and click Request without payment — you should get HTTP 402 with a machine-readable price.
  2. Pay on-chain (Studio web, or CLI: genlayer write <contract> buy_access --args 1 --value 1000000000000000000), wait for finalization.
  3. Paste the tx hash + your buyer address below and click Retry with payment.


In demo mode (no contract configured) the gateway accepts X-Payment: demo and serves the local catalogue. That is a demo shortcut, not a real payment.
