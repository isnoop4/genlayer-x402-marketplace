Try the 402 flow

  1. Pick a listing below and click Request without payment — you will see the HTTP 402 challenge with a machine-readable price, exactly as the gateway returns it.
  2. Pay on-chain (Studio web, or CLI: genlayer write <contract> buy_access --args 1 --value 1000000000000000000), wait for finalization.
  3. Paste the tx hash below and click Check payment — this static page cannot verify it (that needs the gateway), so it links you to the transaction on the explorer and shows the command to serve the data locally.

Live payment check needs the gateway: the gateway loads the tx with genlayer-js and requires from == buyer, to == contract, and the decoded call to be buy_access / buy_credits for that listing with the right value.
