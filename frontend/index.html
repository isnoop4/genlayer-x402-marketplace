Try the 402 flow

  1. Pick a listing and click Request without proof — you get HTTP 402 with a machine-readable price.
  2. Pay on-chain from your own account (buy_access or buy_credits) and wait for finalization.
  3. Click Request with wallet proof. The gateway issues a single-use challenge, your wallet signs it, and the gateway checks the signature, your on-chain access, and — for metered and subscription listings — waits for one credit to be consumed on-chain and finalized before it releases the data (this takes a while).

No browser wallet? The same flow runs from a terminal: BUYER_PRIVATE_KEY=0x… node gateway/client.mjs http://localhost:8787 2.



A transaction hash and an address are public on the explorer, so they are no longer accepted as proof. Send tx hash only shows the refusal.
